It depends on how you first put the site on Vercel. Pick the one that matches.

A. Your site is connected to GitHub (most common)

Vercel redeploys by itself every time you push to GitHub.

  1. Open your project folder on your computer.
  2. Replace the old style.css with the new one (and index.html, script.js and images/me.jpg if you haven’t already).
  3. In VS Code, open the terminal and run:
   git add .
   git commit -m "Fix hero name and update links"
   git push
  1. Go to vercel.com, open your project, and click Deployments. A new deployment starts and finishes in about a minute.
  2. Open https://vengateshwari.vercel.app/ and refresh with Ctrl + Shift + R, so the browser doesn’t show the old version.

If you don’t use git on your computer, you can do the same on github.com: open your repository, click Add file → Upload files, drag in the new files, and click Commit changes. Vercel then redeploys on its own.

B. You uploaded the folder directly (no GitHub)

  1. Go to vercel.com and sign in.
  2. Create a new project and upload the updated folder, or run vercel --prod in the terminal if you use the Vercel CLI.
  3. Check the same link after it finishes.

If you still see the old site

  • Refresh with Ctrl + Shift + R, or open the link in a private window.
  • Make sure index.html is at the top level of the folder, not inside another folder.
  • Check that the images folder is named exactly images in lowercase, with me.jpg inside. Vercel is case-sensitive, so Images/Me.JPG won’t load.

Tell me which one you used (GitHub or direct upload) and I can give you the exact clicks.

Editing your portfolio is a simple loop: change the file on your computer, check it in the browser, then push it so Vercel redeploys.

The editing loop

  1. Open the project folder in VS Code.
  2. Preview it: install the “Live Server” extension, right-click index.html, and choose Open with Live Server. The page refreshes every time you save.
  3. Edit and save the file you need (see the table below).
  4. Publish it:
   git add .
   git commit -m "Update portfolio"
   git push

Vercel redeploys on its own in about a minute. Then refresh your site with Ctrl + Shift + R.

If you don’t want to use git

You can edit directly on github.com instead:

  1. Open your repository and click the file, for example index.html.
  2. Click the pencil icon, make the change, and click Commit changes.
  3. Vercel redeploys automatically.

Tips

  • Make one small change at a time, so you can see what broke if something does.
  • File names are case-sensitive on Vercel, so me.jpg and Me.jpg are different files.
  • If the site doesn’t change after you push, open the Deployments tab on Vercel and look for an error message.
